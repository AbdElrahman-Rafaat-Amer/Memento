# 📱 Memento — Smart Reminder App

Memento is a modern, minimal, and productivity-focused reminder app built with Kotlin and Jetpack Compose.
It helps users stay organized through smart notifications, a clean design, and a smooth onboarding experience.




# ✨ Features

- ✔ Create reminders in seconds
- ✔ Smart notifications delivered right on time
- ✔ Beautiful Jetpack Compose UI
- ✔ M3 color system + custom brand palette
- ✔ Simple onboarding / intro screens
- ✔ Light & clean modern design
- ✔ Support for daily, one-time, and custom reminders (optional depending on your plans)
- ✔ Optimized for performance and readability




# 🎨 UI / Design System

Memento uses a custom UI kit:
  - Primary Color: #6C63FF
  - Accent Color: #FFCE47
  - Light Background: #F7F7FA
  - Typography: Inter / Plus Jakarta Sans
  - Rounded Components: 12dp–16dp
  - Minimal iconography




# 🚀 Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- ViewModel
- StateFlow
- Navigation Compose
- Room — local storage
- DataStore — preferences
- WorkManager — scheduled notifications
